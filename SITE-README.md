# Nurlan Rahimli — Academic Editorial Site

Warm-paper (#FFF1E5) academic homepage, designed for GitHub Pages. Source files: index.html, style.css, script.js, favicon.svg.

## Publish
GitHub Settings → Pages → Deploy from a branch → select **academic-editorial-2026** and **/(root)** → Save. On this repository the website URL will be https://nurlanrahimli1996.github.io/Nurlan-Portfolio/ .

## Edit
Update HTML text in index.html, appearance in style.css, chart/menu interaction in script.js. Add an academic email to the `academicEmail` variable in script.js to enable contact.

The chart and diagram are conceptual examples, not empirical results.
